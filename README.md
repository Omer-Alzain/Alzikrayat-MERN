# Alzikrayat — MERN Edition

A full-stack photo-sharing application rebuilt from the original Alzikrayat PHP project using React, Node.js, Express, MongoDB, and Mongoose.

The application keeps the original Alzikrayat identity and core features: account registration and login, a photo gallery with different layouts, photo uploads, photo details, and comments.

## Project structure

- `client/` — React frontend built with Vite.
- `server/` — Express REST API, Mongoose models, and uploaded photos.

## Requirements

- Node.js 20 or later
- MongoDB local installation or MongoDB Atlas database
